عن تطبيق Site Master Electrical

حالة التطبيق: مكتمل جاهز للتشغيل الفعلي والتخزين المحلي 100% بدون إنترنت (PWA Offline Ready).

المحطات التقنية المنفذة:

  • IndexedDB Engine متكامل لتخزين البيانات والصور (Base64/Blobs).
  • تفعيل Persistent Storage لمنع المتصفح من مسح قاعدة البيانات تلقائياً.
  • دعم الكاميرا والاستوديو معاً لرفع الفواتير والصور بسهولة.
  • Multi-Project Architecture بفلترة تلقائية لكافة الجداول بقيمة `projectId`.
  • Daily Site Report مع تصدير PDF عربي بأسلوب هندسي دقيق.
  • PWA Install Handler للعمل كتطبيق موبايل مستقل.
  • تصدير واستعادة نسخ JSON كاملة للبيانات والصور.
